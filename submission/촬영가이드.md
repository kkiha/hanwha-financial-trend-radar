# 3분 영상 촬영 가이드

## 실행

`hanwha-radar-demo.html`을 Chrome 또는 Edge로 여세요. Python·서버·API 키가 필요 없습니다. 제출할 때 HTML 파일 하나만 전달해도 됩니다. 폰트·로고·데이터가 모두 포함돼 있습니다.

저장된 기사 스냅샷을 사용하며 회사별 브리핑 문장은 기능 설명을 위한 시연 예시입니다. 실제 분석 성공이나 회사의 확정된 입장을 나타내지 않습니다. 화면과 다운로드 자료에도 시연 표시가 들어갑니다.

## 촬영 전

- 브라우저를 최대화하고 확대율을 100%로 설정합니다. 1920×1080 녹화를 권장합니다.
- 처음 화면은 주소 끝의 `#/`로 돌아오면 됩니다.
- 알림을 끄고 다운로드 창이 화면을 가리지 않도록 정리합니다.
- 원문 링크는 외부 웹사이트이므로 인터넷이 필요합니다. 촬영에서는 근거 패널 안의 제목·출처를 보여주는 것으로 충분합니다.
- ‘분석 과정 시연’은 약 5초의 애니메이션이며 실제 수집·AI 호출을 하지 않습니다. 반복 실행할 수 있습니다.

## 확인된 동작

- 인터넷 연결이 없는 상태에서 HTML 직접 실행
- 세 회사 카드 이동 및 상세 브리핑 표시
- 상세 화면에서 전체 논의자료 버튼 숨김
- 분석 과정 시연 완료·재실행
- 근거 패널 열기·Escape 닫기
- 논의자료 HTML 다운로드
- 모바일 가로 넘침 없음, JavaScript 오류 없음

다운로드 HTML/PDF의 페이지 수는 내용과 인쇄 설정에 따라 달라질 수 있습니다. 인쇄 시 A4, 브라우저 머리글·바닥글 끄기를 사용하세요.
