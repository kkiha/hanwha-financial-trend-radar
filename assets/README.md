## 로고

이 디렉터리에 공식 로고 파일 하나를 넣으면 대시보드 헤더와 앱 좌상단 크롬에 자동으로
적용됩니다. 코드 수정은 필요 없습니다.

허용 파일명 (앞에서부터 먼저 발견된 것을 사용):

```
hanwha_logo.svg
hanwha_logo.png
hanwha_logo.jpg
hanwha_logo.jpeg
hanwha_logo.webp
```

- 헤더에서 높이 30px로 렌더되므로 SVG 또는 배경이 투명한 PNG를 권장합니다.
- 파일을 넣기 전에는 헤더가 `Hanwha Financial Trend Radar` 텍스트 로크업으로 표시되며
  레이아웃은 동일하게 유지됩니다.
- 로고는 회사 상표이므로 저장소에 임의로 만든 대체 이미지를 두지 않습니다.
  공식 자산만 배치하세요.
